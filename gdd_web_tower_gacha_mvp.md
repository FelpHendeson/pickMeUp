## Contexto histórico

O MVP original propunha:

- jogo web single-player local;
- invocação/gacha;
- heróis procedurais;
- formação de 5;
- combate automático;
- Torre inicial de 10 andares;
- recursos e equipamentos simples;
- persistência em localStorage;
- expansão futura para Base, expedições e progressão.

Desde então o projeto migrou para Next.js/React/TypeScript/Zustand, adotou roster único, Lobby Vivo, 40 andares, readiness, treino, proficiências, potencial, promoção, migrations formais de save e uma nova arquitetura de UX.

**Não use os números, stack, roadmap ou escopo deste documento histórico como requisito atual.**
